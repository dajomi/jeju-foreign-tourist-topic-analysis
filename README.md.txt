# LDA 토픽모델링을 이용한 제주도 외국인 관광객 여행 테마 분석

## 프로젝트 개요
TripAdvisor 리뷰 데이터를 활용하여 제주도 외국인 관광객의 여행 테마를 분석한 프로젝트입니다.

## 기술 스택
- Python
- QGIS
- LDA Topic Modeling
- Hotspot Analysis

## 주요 결과
- 외국인 관광객은 하이킹, 화산지형, 조경, 전시/실내 체험 중심의 관광 테마를 선호하는 경향을 보였습니다.
